# Choose Sui guidance by task and authority

As of 2026-10-18, the strongest general-purpose Sui coding candidate in the surveyed sources is Mysten Labs’ modular, Apache-2.0 [Agent Skills pack](https://github.com/MystenLabs/skills), with official Sui, SDK, Walrus and Move Book documentation indexes as complementary on-demand references. Community projects add narrower audit, Move checklist and protocol-specific guidance, while MCPs range from documentation search to tools that hold private keys and submit transactions. Those capabilities should be assessed separately: loading a skill is not the same as granting an MCP authority. The notes provide repository metadata, file sizes and documented behaviors, but no paired implementation spot-checks; therefore they support no claim about quality, saved turns or tokens. Version targets, documentation rights, MCP authentication and integration into the public AGPLv3 fleet skill repository remain gaps or decisions for the owner.

## One official skill pack covers most app development areas

The Mysten Labs [skills repository](https://github.com/MystenLabs/skills/blob/main/README.md) is the broadest reusable app-development candidate found. Its README offers selective or full installation through `npx skills add mystenlabs/skills` for Claude Code, Cursor, Codex and other compatible agents, and recommends a three-skill starter set. The 2026-10-15 main commit observed by the researchers was [`e31b38016723`](https://github.com/MystenLabs/skills/commit/e31b38016723); repository metadata identifies Apache-2.0 ([license](https://github.com/MystenLabs/skills/blob/main/LICENSE)). The inspected catalog lists 31 top-level entries and 33 `SKILL.md` files. Their combined size is 257,875 bytes, roughly 64,000 tokens at the notes’ bytes-divided-by-four estimate, excluding supporting references and evals. This is a bundle total, not a measured prompt cost: supporting files are described as conditional, and relevant trigger files are much smaller (for example, `sui-move` 6,641 B/~1,700 tokens, `object-model` 10,708 B/~2,700, `ptbs` 10,134 B/~2,500, `sui-sdks` 12,690 B/~3,200). ([catalog](https://github.com/MystenLabs/skills/blob/main/README.md), [recursive tree](https://api.github.com/repos/MystenLabs/skills/git/trees/main?recursive=1))

It explicitly covers Move 2024, object model, PTBs, TypeScript and Rust SDK guidance, CLI/build/test/publish, Walrus Sites, DeepBook V3, zkLogin, and Move testing/security. The checked skill inventory found no dedicated localnet or Seal skill; that is a finding about named skill paths, not proof that these subjects never appear incidentally. No single Sui CLI or `@mysten/*` version pin was found, so the pack follows its moving branch and linked current documentation. Some skills guide client configuration, faucet use, publishing/upgrading, signing, or transaction construction. They are instructions rather than an MCP that itself executes those actions, but agents following them can still initiate consequential commands. ([Move skill](https://github.com/MystenLabs/skills/blob/main/sui-move/SKILL.md), [client skill](https://github.com/MystenLabs/skills/blob/main/sui-client/SKILL.md), [publish skill](https://github.com/MystenLabs/skills/blob/main/sui-publish/SKILL.md), [TypeScript backend skill](https://github.com/MystenLabs/skills/blob/main/sui-ts-sdk-backend/SKILL.md))

An older MystenLabs [`sui-dev-skills`](https://github.com/MystenLabs/sui-dev-skills/blob/main/README.md) repository has nine skills totaling 79,446 B/~19,900 estimated tokens, with Move, TypeScript SDK v2 and frontend coverage. Its last observed commit was 2026-03-18 (`e3657857fbe4`). No license file or GitHub license classification was found, so its redistribution/use status is unresolved. No source in the notes explicitly deprecates it in favor of the newer pack. It also guides transaction construction/execution and wallet integration; no direct MCP was identified. These facts make it a comparison source pending license and maintenance clarification, not a ready-to-vendor candidate. ([tree](https://api.github.com/repos/MystenLabs/sui-dev-skills/git/trees/main?recursive=1), [commit](https://github.com/MystenLabs/sui-dev-skills/commit/e3657857fbe4))

## MCPs must be judged by their granted authority

Two distinct documented MCP offerings surfaced. The Walrus Console MCP is a local package, [`@mysten-incubation/walrus-console-mcp`](https://github.com/MystenLabs/ts-sdks-incubation/tree/main/packages/walrus-console-mcp), described in [Walrus docs](https://docs.wal.app/docs/console/mcp-server) as MIT licensed, with 17 Walrus file/space/folder tools. It requires a Console API key and `suiprivkey1` service key; docs say it locally signs Sui access-grant transactions, unwraps Seal keys, can mint child keys and submit sponsored `grant_bucket_access` transactions. It is useful for Console file operations, not general contract development. Package source commit/version and exact runtime schema/result token cost were not established; the installer was not run.

A Walrus docs server card identifies a remote “Walrus Documentation” service at `https://sui.mcp.kapa.ai/`, server version 1.0.0, for docs search and Q&A. The notes say its card requires a Kapa API token, while the Sui docs setup page describes the docs MCP as OAuth with per-user daily limits ([server card](https://github.com/MystenLabs/walrus/blob/main/docs/site/static/.well-known/mcp/server-card.json), [Sui MCP setup](https://docs.sui.io/getting-started/sui-mcp-server)). These descriptions differ; the correct auth path for a particular client was not resolved. Neither source establishes Kapa as a Mysten-operated service, a vendorable license, chain-state access, or transaction/key authority. No endpoint was called.

The community [abhinavg6 MCP](https://github.com/abhinavg6/sui-mcp-server) claims a read-oriented gRPC/GraphQL and package-introspection interface, execution disabled by default, and pre-signed-transaction forwarding as the only execution mode if enabled. This was not independently audited. The [ExpertVagabond MCP](https://github.com/ExpertVagabond/sui-mcp-server) describes a much broader interface that imports private keys and can sign transfers, Move calls and staking transactions; its package and README SDK version claims conflict. The SUI Dev Agents plugin also bundles a query and agent-wallet MCP. None of these broad action surfaces is necessary merely to retrieve documentation; enabling them would be a separate authority decision.

## Candidate fit remains an evidence question

As reported facts, the Mysten skills pack is the only surveyed broad app-builder collection explicitly documented for Codex and multiple other harnesses, while the docs indexes provide a smaller retrieval route when fetched selectively. The community candidates supply differentiators rather than a clearly superior general pack: source-backed audit workflow (`exvulsec`), a compact Move checklist (Pappas), and NAVI operations for a project that uses NAVI. These comparisons do not establish better answers or reduced work. The broad SUI Dev Agents bundle duplicates the official skills and adds a key-capable execution surface; its own version claims and JSON-RPC description warrant verification before any adoption.

The reports contain no paired bounded Implementer tasks with and without candidates, no spot-check turns/tokens/outcomes, and no measured injection costs. They also contain no exhaustive audit of every source page, no verified SDK-doc license, no Kapa auth resolution, and no runtime security review of MCP code. Thus there is no evidence-based ranking by fleet pain reduction or projected savings here. Any recommendation to integrate into the public AGPLv3 `agent-skills` repository needs Ted’s license and product ruling: Apache/MIT or repository-level licenses are useful source facts, not an automatic compatibility/legal determination; content licenses may differ from code licenses. Candidate versions were mostly moving `main` branches or README claims rather than pinned toolchain targets, so a version-aware manifest and a repeatable update process would be needed to keep guidance aligned with each project’s `Move.toml`, package manifests and installed CLI.

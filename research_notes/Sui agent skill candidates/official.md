# Official Sui, Move, and Walrus agent-skill candidates

Observation date: 2026-10-18. This is a scoped first-party-source survey, not an install, RPC run, transaction, or skill quality experiment. Local repo reads were read-only. The date/byte observations below were taken against the live `main` branches/endpoints on 2026-10-18; they can drift.

## Which official skills, agent instructions, plugins, and MCPs exist?

### Takeaway

The clear cross-harness, downstream-app candidate is [`MystenLabs/skills`](https://github.com/MystenLabs/skills): a current Apache-2.0 Agent Skills collection, installable through `skills` CLI for Claude Code, Cursor, Codex, and other compatible agents. Separate first-party repositories also contain contributor-facing skills and instructions; these are targeted at maintaining Mysten repos. Mysten publishes a Walrus Console MCP with file and Sui-grant operations. The Sui-docs MCP hostname mentioned in the skills is Kapa-hosted docs Q&A, not evidence of a Mysten-shipped general Sui blockchain-operation MCP.

### Inferences
- For fleet development across apps, the Mysten Agent Skills pack is the only surveyed single source designed and documented for reusable end-user Sui work across both Claude Code and Codex; it can be selectively loaded, but CLI/publish/signing skill triggers need explicit local policy boundaries. This follows from its README’s supported-client list, modular layout, and `sui-client`/`sui-publish`/backend content. [README](https://github.com/MystenLabs/skills/blob/main/README.md)
- A limited read-only documentation MCP exists at Kapa’s endpoint; the separate Walrus Console MCP is useful for Walrus storage operations but introduces credentials, filesystem access and Sui write authority. [Walrus server card](https://github.com/MystenLabs/walrus/blob/main/docs/site/static/.well-known/mcp/server-card.json), [Console MCP guide](https://docs.wal.app/docs/console/mcp-server)
- Repository contributor guidance is suitable as scoped references when an agent is changing that specific upstream repository; its presence is not evidence of a reusable agent plugin or downstream project skill. [Sui repo](https://github.com/MystenLabs/sui), [ts-sdks AGENTS](https://github.com/MystenLabs/ts-sdks/blob/main/AGENTS.md), [Walrus repo](https://github.com/MystenLabs/walrus)

The browser text renderer surfaced errors for some full files, but the direct HTTP checks returned their statuses/byte counts; the SDK `llms-full.txt` 404 body size is not a documentation corpus.
